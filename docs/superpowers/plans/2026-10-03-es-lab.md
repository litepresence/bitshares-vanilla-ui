# ES Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `#/es-lab` community-index browser (api-lab twin) per `docs/superpowers/specs/2026-10-03-es-lab-design.md` — curated ops/holders searches + raw DSL console, read-only, pref-gated, never load-bearing.

**Architecture:** `vanilla/js/api/es-lab.js` owns the query-template catalog + pure `build`/`parse`/`run` helpers (no DOM); `vanilla/js/views/es-lab-ui.js` owns the desk (DOM only). Sole ES transport is `HistoryCap.esSearch`. Op-type display names come from a new `Explorer.opName` accessor (single owner, no duplicated table).

**Tech Stack:** Vanilla JS (classic `<script>` globals, `"use strict"` IIFEs), platform `fetch` (via `HistoryCap` only), WebSocket-free. Node stdlib tests (`node tooling/es-lab-test.js`, `assert` only).

## Global Constraints

- Zero runtime dependencies, no CDN, no build step; `python3 -m http.server` serves a working app.
- Sole ES path: `HistoryCap.esSearch(index, body, {timeoutMs})` — never call `fetch` for ES anywhere else.
- Money stays raw strings until the view formats via `Format.formatAmount(String, prec)` / `Format.pct1(count, total)` — no `Number()`, no float math on money.
- `textContent`-only DOM insertion; no `innerHTML` with chain/ES strings; no `eval`.
- Module headers + function docs on every new file (§3.7); no TODO/FIXME/commented-out code.
- `node --check` on touched JS + `python3 tooling/check_rot.py` + `bash tooling/check_types.sh` + `python3 tooling/check_i18n.py` green before every task commit.
- i18n: `I18n.t("eslab.*", "verbatim default")` in code, dict entries shipped in the same task (never a follow-up).
- Git: `git add` EXACT file paths only (never `git add -A`); `git status --short` must show only the task's files before commit.

**Files:**
- Create: `vanilla/js/api/es-lab.js`
- Create: `tooling/es-lab-test.js`

**Interfaces:**
- Consumes: `HistoryCap.esSearch(index, body, {timeoutMs})`, `HistoryCap.esAllowed()`, `Explorer.opName(id)`.
- Produces: `EsLab.TEMPLATES` (array), `EsLab.byKey(key)`, `EsLab.build(tpl, values)` → `{index, body}`, `EsLab.parse(tpl, json)` → row array, `EsLab.run(tplKey, values, opts)` → Promise, `EsLab._test`. Task 5 consumes `TEMPLATES`/`byKey`/`build`/`parse`/`run`.

Template entry shape: `{ key, index, title, desc, sourceRef, fields: [{name, type, required, example, hint}], build: fnName, parse: fnName }` with `build`/`parse` as named module functions (testable, no closures over DOM).

Field types mirror api-lab: `string | uint | json | strlist`. Reuse its coercion semantics: `uint` rejects non-`^[0-9]+$`, `json`/`strlist` go through `JSON.parse`, missing required throws `missing: <name>`.

Seed templates this task (bodies below are VERBATIM from in-tree/astro precedents — do not improvise):

1. `holders-by-asset` (`objects-balance`) — astro `TopAssetHolders.ts:28-37`:
```js
{ query: { bool: { must: [{ match: { asset_type: { query: assetId } } }] } },
  track_total_hits: false, size: 25, sort: [{ balance: { order: "desc" } }] }
```
parse: `(json.hits.hits || []).map(h => ({owner: h._source.owner_, balance: String(h._source.balance ?? "0")}))`, drop empty owners. Balance display stays a STRING until the view formats it.

2. `fills-by-market` (`bitshares-*`) — `vanilla/js/api/market-fills-history.js:83-92`:
```js
{ sort: [{ "block_data.block_time": { order: "desc", unmapped_type: "boolean" } }],
  size: 500,
  _source: ["account_history", "operation_history", "operation_type", "block_data"],
  query: { bool: { must: [
    { match: { operation_type: "4" } },
    { multi_match: { type: "best_fields", query: baseSym, lenient: true } },
    { multi_match: { type: "best_fields", query: quoteSym, lenient: true } } ] } } }
```

3. `top-ops-agg` (`bitshares-*`) — astro `TopOperations.ts:47-64`, lookbackDays param → `gte: "now-<N*24>h"`:
```js
{ size: 0,
  query: { bool: { filter: [{ range: { "block_data.block_time": { gte: "now-720h", lte: "now" } } }] } },
  aggs: { by_op_type: { terms: { field: "operation_type", size: 200 } } } }
```
parse: buckets → `{type, name: Explorer.opName(b.key), count: b.doc_count, share: Format.pct1(b.doc_count, total)}`.

4. `pool-swaps` (`bitshares-*`) — `vanilla/js/api/pool-history.js:65-72`: same sort/size/_source envelope as (2), `must: [{ match: { operation_type: "63" } }, { multi_match: { type: "best_fields", query: poolId, lenient: true } }]`.

`run(tplKey, values, opts)`: `build` → `HistoryCap.esSearch(tpl.index, body, {timeoutMs: (opts&&opts.timeoutMs)||15000})` → `parse`. Plus paged variant `runPaged` (Task 3).
