- [ ] **Step 3: Implement preset table + plumbing (calm = current constants verbatim)**

```js
/* PHYS presets: calm (v1 shipped behavior, byte-identical constants) vs lively
 * (pyvis-barnesHut character: inverse-square degree-mass repulsion, long weak
 * springs, high carryover, weak center pull, late sleep gate, curved edges).
 * stepFrame/drawScene read S.phys; nothing else branches. */
var PHYS = {
  calm:   { repPow: 1, repK: 1.0, repCap: 5, carry: 0.8, temp0: 6, cool: 0.98, tempMin: 1,
            springRest: 1.1, springK: 0.0015, pull: 0.008, btsPullX: 3,
            stillTol: 0.35, stillFrames: 25, minFrames: 0, curved: false },
  lively: { repPow: 2, repK: 2.6, repCap: 40, carry: 0.92, temp0: 10, cool: 0.995, tempMin: 0.5,
            springRest: 2.4, springK: 0.006, pull: 0.003, btsPullX: 3,
            stillTol: 0.2, stillFrames: 90, minFrames: 180, curved: true }
};
function _physForTest() { return PHYS; }
function _defaultPhysForTest() { return "calm"; }
```

`stepFrame(S)`: `var P = PHYS[S.phys] || PHYS.calm;` then replace literals:
repulsion `f = Math.min((k*k)/(d*d+1)*2, 5)` →
`var deg = 1 + (S.deg ? (S.deg[a] + S.deg[b]) : 0);`
`var f = P.repPow === 2 ? Math.min(P.repK * k * k * deg / (d*d*d + 1), P.repCap) : Math.min((k*k)/(d*d+1)*2, P.repCap);`
springs `f2 = (ed - k*1.1) * 0.015` → `f2 = (ed - k * P.springRest) * P.springK;` (keep the existing `* ed * 0.1` application lines untouched).
pull `0.008` → `P.pull`; carry `* 0.8` → `* P.carry`; `S.temp * 0.98, 1` → `S.temp * P.cool, P.tempMin`.
`loop(S)`: add frame counter `S.frames = (S.frames || 0) + 1` per frame; sleep gate →
`if (moved < P.stillTol) S.still++; else S.still = 0;`
`if (S.still >= P.stillFrames && (S.frames || 0) >= (P.minFrames || 0)) { ...sleep... }`
reset `S.frames = 0` in `wake(S)` alongside `S.still = 0`; `S.temp = P.temp0` in `wake` (read preset at wake time so a flip re-energizes).
`drawScene` edge stroke: `if (P.curved) { quadratic midpoint offset perpendicular by ((edgeIndex % 5) - 2) * 6px } else { straight lineTo }` — pass `S.phys` into existing draw opts.
Header: segmented two-button control (`Calm`/`Lively`, `aria-pressed`, 44px, `touchable`), reads `localStorage poolNetPhys` (`"lively"` → lively else calm), writes on flip, calls `wake(S)` so the new preset re-settles from current positions. Reduced-motion: existing `S.reduced` freeze covers both (no new branch).
Keys: `pool_net.phys_calm` = `"Calm"`, `pool_net.phys_lively` = `"Lively"` via `I18n.t` verbatim defaults; sync non-en via Task-7 adder pattern (honest English stubs).
