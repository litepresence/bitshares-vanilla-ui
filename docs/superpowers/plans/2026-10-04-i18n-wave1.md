## Shared translator rules (verbatim in every prompt)

1. Read ONLY your assigned sections from `vanilla/locales/en.json`.
2. Glossary first: fix target terms for witness, committee, worker, proxy,
   brainkey, vesting, HTLC, swap, slate, account, asset, market, order, fee,
   collateral, margin, settlement, proposal, pool, stake, vote — use them
   consistently, report the table in your reply.
3. Preserve EXACTLY: `%(name)s` multisets, URLs, `1.2.x` ids, op numbers,
   asset symbols (BTS/USD/…), theme/network ids, `\n` newlines,
   leading/trailing spaces, punctuation characters (… — ✓ →).
4. Fragments (`*_prefix/*_suffix/*_mid`) assemble in code — pick forms that
   concatenate; FLAG impossible ones, never silently reorder.
5. Identifiers stay English: mainnet/testnet, theme ids, "BitShares",
   "BITSHARES", brand names; link texts keep their URLs.
6. Output: `/tmp/i18n-<lang>-<chunk>.json`, nested, COMPLETE (zero dropped
   keys). Never paste translations in chat. Reply: counts + glossary + flags.
7. No repo writes except the /tmp file. No commits.
