# Vendored-artifact upstream watch

Scope: this file is a dev-only manifest. It ships as a static `.md` doc
inside `vanilla/` (docs ship statically; never executed, never imported)
and MUST stay small. It is the "watch" half of vendor-never-depend
(AGENTS.md §4.5 rule 3): every pinned copy below names what would force
a re-vendor and how.

Cadence: upstream checks run every slice (during the slice's audit pass)
plus on demand when a CVE/security release touches our used surface.

Re-vendor procedure (all rows): byte-diff candidate vs pin; full vector
suites green (`tooling/prove_signing_restored_40hex.cjs`,
`tooling/txbuilder-test.js`, `tooling/witness-serializers-test.js` as
applicable); testnet sign proof (connect → sign → broadcast observed);
update the provenance note (`js/vendor/PROVENANCE.md` or
`assets/PROVENANCE.md`) with new pin + sha256. Never hand-edit a vendored
file — re-vendor or regenerate it.
